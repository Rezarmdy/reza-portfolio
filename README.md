# Reza Romadoni - Portfolio

Static website. No installation or build step is required.

## Publish with GitHub and Cloudflare Pages

Upload the contents of this folder to a GitHub repository owned by Reza.
In Cloudflare Pages, connect that repository. Select no framework, leave the
build command blank, and use the repository root as the output directory.
Use main as the production branch. Configure automatic production deployments
from main; use another branch for previewing changes before merging.

The generated pages.dev address is assigned by Cloudflare; no public URL has
been reserved or published as part of this local package.

## Update content

- Introduction, profile, contacts and languages: index.html.
- Project titles, short descriptions, categories and gallery paths: projects.js.
- Featured project order, design tools and skill tags: app.js.
- Styling and responsive layout: style.css.
- Images, application marks and downloadable CV: assets/.

Keep project IDs stable. Categories must match the filter labels exactly:
Campaign, Social Media, Videography & Motion. Set a project cover and gallery
paths to the files under assets/. Update source on a preview branch, check it,
then merge into main to update the existing public website.
